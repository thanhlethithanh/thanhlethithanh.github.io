## Data Analysis Portfolio Workspace
This folder includes a Jupyter-based data analysis portfolio and the workspace configuration for local development.

### Setup
1. Activate the Python virtual environment:
   - `d:/my-portfolio/venv/Scripts/activate`
2. Install dependencies:
   - `python -m pip install -r requirements.txt`
3. Launch the Jupyter workspace:
   - `python -m jupyter lab`

### VS Code
- Uses the local interpreter at `${workspaceFolder}/venv/Scripts/python.exe`
- Recommended extensions: Python, Jupyter, Pylance
